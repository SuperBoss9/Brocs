Browser Connection Status (Brocs) показывает, как браузер соединился с основным документом текущей вкладки — локально, без отправки данных наружу.

Для страниц HTTP/HTTPS Brocs сообщает:

• семейство IP: IPv4 или IPv6 (по фактическому remote IP основного документа);
• версию HTTP: HTTP/1.0, HTTP/1.1, HTTP/2 или HTTP/3, если браузер её предоставляет;
• режим proxy: прямое соединение, фиксированный proxy или AUTO (PAC / system / auto-detect);
• подробности при наведении: host, remote IP, транспорт (QUIC для HTTP/3), код ответа и признак cache, если доступны.

Кнопка на панели
На кнопке расширения отображается короткий статус вроде 6H3 или 4H2 (семейство IP + HTTP). Цвет фона иконки отражает режим proxy. При наведении показывается tooltip с полной сводкой по вкладке.

Только основной документ
Анализируется запрос main_frame (основной HTML), а не картинки, скрипты, iframe и analytics. Если страница загружена по IPv6 + HTTP/3, а ресурс — по IPv4 + HTTP/2, Brocs показывает IPv6 / HTTP/3.

Для кого
Разработчики, сетевые инженеры и опытные пользователи, которым нужен быстрый и достоверный взгляд на dual-stack, HTTP/3, proxy и VPN без отдельных утилит.

Конфиденциальность
Brocs работает только локально: без внешних API, без analytics и без передачи истории, hostname, IP или настроек proxy.

Ограничения MVP
Нет DNS-диагностики, анализа TLS-сертификатов и lookup публичного IP. Для PAC / system / auto-detect показывается AUTO — фактический маршрут каждого запроса через proxy средствами браузера достоверно не определяется.

Для Chromium-совместимых браузеров, включая Chrome и Яндекс Браузер (Manifest V3).
